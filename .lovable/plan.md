# Simplify the CareBox dashboard

## What will change
- Put recent prescriptions before the family list so the latest records are easier to find.
- Replace the horizontally swiped family shelf with a compact responsive grid that shows every member without hidden cards.
- Remove the dashboard-only member filter and unsupported “Private & encrypted” claim; keep the existing record search link, counts, family colors, and prescription thumbnails.
- Trim secondary copy and card details while preserving add, open, empty, and loading states.

## Technical details
- Keep changes within the dashboard presentation; do not change data, routes, or database behavior.
- Check the dashboard at phone, tablet, and desktop widths and confirm the current build has no errors.
